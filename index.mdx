## What is Doge Unblocker?

Doge Unblocker routes your web traffic through a Node.js server using the Ultraviolet Service Worker proxy. URLs are XOR-encoded before being forwarded through the `/bare/` relay, so the destination never appears in your browser's address bar or network logs as a recognizable domain.

On top of the core proxy, Doge Unblocker ships a full suite of stealth features — tab cloaking presets, about:blank windows, a configurable panic key, and clickoff auto-disguise — to keep the session invisible to monitoring software like DyKnow and GoGuardian.

## Get Started in Three Steps

<Steps>
  <Step title="Clone and install">
    Clone the repository and install dependencies with npm.
    ```bash
    git clone https://github.com/DogeLeader/DogeUnblocker-v4.git
    cd DogeUnblocker-v4
    npm install
    ```
  </Step>
  <Step title="Start the server">
    Start the Node.js server. It listens on port 8000 by default.
    ```bash
    npm start
    ```
  </Step>
  <Step title="Open the proxy">
    Navigate to `http://localhost:8000` in your browser, enter any URL or search query, and hit Enter to start proxying.
  </Step>
</Steps>
