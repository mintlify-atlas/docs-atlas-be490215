Doge Unblocker ships two dedicated library pages — `/apps` for web applications and `/gms` for browser games. Every entry is routed through the Ultraviolet proxy, so no direct connection is ever made from your device to the destination service. Both pages use an `IntersectionObserver`-based lazy-loader so only visible cards are rendered, keeping page load times fast even with large catalogues.

<Note>
  All apps and games are proxied through Ultraviolet. Your browser never connects directly to the destination — every request passes through the bare server at `/bare/`, masking the true destination from network-level filters.
</Note>

The apps page is served at the `/apps` route and populated dynamically by `apps.js`. Each entry is registered in the `apps` object and then injected into the DOM by `addApp()`.

### How `addApp()` Works

Each app card is created programmatically so new entries can be added to the `apps` object without touching any HTML:

```javascript
// static/assets/js/apps.js

function addApp(name, imageUrl, onClickFunction, width, height) {
  var appContainer = document.getElementById('appContainer');
  var linkElement  = document.createElement('a');
  linkElement.href      = "#";
  linkElement.className = "square_btn";
  linkElement.onclick   = onClickFunction;

  if (width)  linkElement.style.width  = width  + 'px';
  if (height) linkElement.style.height = height + 'px';

  var imageElement       = document.createElement('img');
  imageElement.className = "rounded";
  imageElement.src       = imageUrl;
  imageElement.alt       = name;
  imageElement.draggable = false;

  var brElement   = document.createElement('br');
  var textElement = document.createTextNode(name);

  linkElement.appendChild(imageElement);
  linkElement.appendChild(brElement);
  linkElement.appendChild(textElement);

  appContainer.appendChild(linkElement);
}
```

The `apps` object maps each app name to its icon path, click handler function, and optional `width`/`height` overrides (used by tall cards like Symbolab and VS Code).

### Lazy-Loading with IntersectionObserver

`loadApps()` is called once the page is ready. It attaches an `IntersectionObserver` to every `.square_btn` element and only adds the `loaded` CSS class (which triggers the fade-in animation) when a card scrolls into the viewport:

```javascript
// static/assets/js/apps.js

function loadApps() {
  const squareBtns = document.querySelectorAll('.square_btn');

  const observer = new IntersectionObserver(entries => {
    entries.forEach(entry => {
      if (entry.isIntersecting) {
        loadSquareBtn(entry.target);
        observer.unobserve(entry.target);
      }
    });
  });

  squareBtns.forEach(btn => observer.observe(btn));
}

function loadSquareBtn(btn) {
  btn.classList.add('loaded');
}
```

### Search

The apps page includes a live search bar (`#searchApps`). As you type, it filters the visible app cards by their inner text in real time:

```javascript
// static/assets/js/apps.js

document.getElementById('searchApps').addEventListener('input', function(event) {
  const query = this.value.toLowerCase();
  const links = document.getElementsByClassName('search-results')[0]
                        .getElementsByTagName('a');
  let foundResults = false;

  for (let i = 0; i < links.length; i++) {
    const link     = links[i];
    const linkText = link.innerText.toLowerCase();
    if (linkText.includes(query)) {
      link.style.display = 'block';
      foundResults = true;
    } else {
      link.style.display = 'none';
    }
  }

  const message = document.getElementById('searchMessage');
  if (!foundResults) {
    message.innerText      = 'No Results Found.';
    message.style.display  = 'block';
  } else {
    message.style.display  = 'none';
  }
});
```

### How Games Are Launched (`agloader.html`)

When you click a game on `/gms`, the game's URL is written to `localStorage`:

```javascript
// Pattern used on the /gms page for each game tile
localStorage.setItem('agUrl', gameUrl);
location.href = '/lessons';
```

The server routes `/lessons` to `agloader.html`, which reads `agUrl` from `localStorage` and injects it as the `src` of a full-screen `<iframe>`. The `vAG()` function in `functions.js` allows the right-click context menu to re-open the last visited game directly:

```javascript
// static/assets/js/functions.js

function vAG() {
  var checkHistory = localStorage.getItem('agUrl');
  if (checkHistory !== null) {
    location.href = '/lessons';
  } else {
    alert('Could not find a previously visited app/game, visit one first!');
  }
}
```
