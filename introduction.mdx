Doge Unblocker is an open-source, self-hosted web proxy that lets you access blocked websites through your own server. Built on Node.js and Express, it leverages the [Ultraviolet](https://github.com/titaniumnetwork-dev/Ultraviolet) proxy engine and the TOMP bare server to rewrite and forward web traffic through a Service Worker — all without installing any browser extension.

## What Is Doge Unblocker?

Network filters and firewalls — common in schools, workplaces, and public networks — block access to websites by inspecting URLs and DNS requests. Doge Unblocker works around these restrictions by proxying traffic server-side and routing it through an obfuscated `/service/` path, making blocked sites appear as ordinary requests to your own domain.

Every URL entered into the proxy bar is encoded using XOR encryption before being passed to the Ultraviolet Service Worker. The Service Worker intercepts fetch events and transparently forwards requests through the bare server (`/bare/`), then returns the response to the browser — without the target URL ever appearing in plain text in the network log.

## Tech Stack

| Layer | Technology |
|---|---|
| Runtime | Node.js ≥ 16 |
| Web framework | Express 4 |
| Proxy engine | Ultraviolet (Service Worker) |
| Bare transport server | `@tomphttp/bare-server-node` |
| URL encoding | XOR codec (`Ultraviolet.codec.xor`) |
| License | GPL-3.0-or-later |

## Current Version

Doge Unblocker is currently on **version 4.4.7**. The project requires **Node.js ≥ 16.0.0** and **npm ≥ 7.0.0** to run.
